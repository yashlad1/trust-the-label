## Pilot setup

The pilot used 12 jobs, 3 of each kind: delete (s01, s05, s08), send (snd03, snd06, snd10), pay (pay03, pay04, pay08) and publish (pub01, pub02, pub04). These are the same 12 jobs, drawn at random in the Nov 15 pilot (seed 20261115, which is not recorded in these logs); their files are in `dev/pilot-jobs/`. Each job ran in both versions of the user's request, one where the irreversible call was unneeded and one where it was wanted, giving 24 tasks. Each task ran once, and every condition used the same 24 tasks. In stage 1, two agents (gpt-oss-120b and GLM 5.3 Flash) each ran all 24 tasks, for 48 episodes, none of which failed. When an agent proposed an irreversible call, its first one was saved: 34 in all, 12 from the unneeded versions (gpt-oss-120b 75% (9/12), GLM 5.3 Flash 25% (3/12)) and 22 from the wanted versions (92% (11/12) for each agent). In stage 2, each saved action was shown to the gate in 48 different settings ("rows"), which vary the tool name the gate saw, the request, whether the gate saw labels at all and which label and warning it saw, and whether the gate's prompt carried an added sentence about the user's intent; two gates (GPT-6 Luna and Nemotron 3.5 Super VL) each judged all 34 actions in all 48 rows, 1,632 judgments per gate, none of which failed. In stage 3, the agent ran live, using the honest tool name and the false label, with GPT-6 Luna as the gate under three policies (gate on the call alone; labels with the warning off; labels with the warning on), 24 episodes each, none of which failed. The stage-3 agent was gpt-oss-120b: the pipeline picks the stage-1 agent with more unneeded episodes with at least one irreversible call, and gpt-oss-120b had 9 of 12, against 3 of 12 for GLM 5.3 Flash. The whole pilot, from the start of the first log to the end of the last, including a short check run before each stage's main runs, took about 36 minutes (2:00 to 2:37 PM EST on Nov 20, 2026). It ran at commit 89c4089, which is on main as 3727b7f.

How to read: an episode is one agent working on one task; a saved action is the first irreversible call an agent proposed in an episode; a row is one setting in which the gate judged a saved action.
Main takeaway: every later number comes from 24 tasks run once each, 34 saved first actions in stage 2 (only 12 of them unneeded), and 24 live episodes per policy in stage 3, so each rate rests on a small count.
Source: `records/fp3-pilot-final/` (16 logs: 9 main runs and 7 short check runs, 0 failed samples); `uv run python dev/report.py records/fp3-pilot-final/final-*/manifest.json`; n = 48 stage-1 episodes, 3,264 stage-2 judgments, 72 stage-3 episodes.
